# Security policy

## Supported versions

Only the latest release on `main` receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

When GitHub private reporting is available, go to the **Security** tab and choose **Report a vulnerability**. Include the app version, your macOS and TV model or webOS version, and steps to reproduce. If that option is unavailable, ask a maintainer for a private reporting channel without disclosing vulnerability details in public.

Things that count as security issues include:

- Pairing keys, certificates or credentials being written somewhere they should not be, or sent to a host other than the TV you chose.
- Local network access that goes beyond what the app needs to control the TV.
- Usage data leaving the Mac.

Never include your real pairing key, TV serial number, public or local IP address, or MAC address in a report, issue or pull request. If you need to share a log, redact these values first.
